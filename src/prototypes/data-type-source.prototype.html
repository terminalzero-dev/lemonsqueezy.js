引导检查

        

          按顺序体验最容易把“向后兼容 API 变化”变成 SDK 故障的四个场景。
        

        

      


      

        

          请求是闭世界camelCase DTO 与 enum
          严格；未知或拼错字段不发送。
        

        

          响应是开世界运行时保留未知字段；公开已知字段无宽泛
          index signature。
        

        

          入站事件有 fallback已知事件可判别；新增事件作为
          Unknown event 安全接收。
        

        

          冲突不猜文档、示例与观测不一致时记录证据状态，人工裁决后再发布。
