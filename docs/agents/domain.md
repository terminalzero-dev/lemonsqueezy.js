# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

- Read root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- If either location is absent, proceed without treating it as an error.

## Vocabulary

Use terms defined in `CONTEXT.md` in issues, implementation plans, tests, and documentation. Avoid synonyms that the glossary explicitly rejects.

If a required concept is missing, reconsider the terminology or record the gap for `domain-modeling`.

## ADR conflicts

Surface any proposal that conflicts with an existing ADR instead of silently overriding it.
